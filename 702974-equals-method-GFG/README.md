# [Equals Method](https://www.geeksforgeeks.org/problems/equals-method/1?page=1&category=Java&status=unsolved&sortBy=submissions)
## Easy
Given a two integer arrays a[] and b[], return true if both the arrays contain the same elements in the same order. Otherwise, return false.&nbsp;
Example:
Input: a[] = [1, 2, 3, 4], b[] = [4, 3, 2, 1]
Output: false
Explanation: Both arrays are not same as they don't contain elements in the same order. So we print false.
Input: a[] = [5, 6, 7, 8, 9], b[] = [5, 6, 7, 8, 9]
Output: true
Explanation: Both arrays are same as they contain the same elements and in same order. So we print true.
Constraints:1&nbsp;≤&nbsp;&nbsp;a.length, b.length&nbsp;≤ 1061&nbsp;≤&nbsp;a[i], b[i]&nbsp;≤&nbsp;106
