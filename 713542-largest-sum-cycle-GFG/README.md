# [Largest Sum Cycle](https://www.geeksforgeeks.org/problems/largest-sum-cycle--170645/1)
## Hard
Given an array edge[] of size n, there are n cells numbered from 0 to n - 1. Each cell has at most one outgoing edge.For every cell i:edge[i] is the cell reached from i in one step.edge[i] = -1 means that cell i has no outgoing edge.A cycle is a sequence of cells where, by following the outgoing edges, we eventually return to the starting cell. The sum of a cycle is the sum of the indices of all cells in that cycle.Return the maximum cycle sum. If there is no cycle, return -1.Examples:Input: edge[] = [1, 2, 0, -1]Output: 3Explanation:&nbsp;There is only one cycle in the graph i.e. 0 -&gt; 1 -&gt; 2 -&gt; 0. Sum of the cell index in that cycle = 0 + 1 + 2 = 3.Input: edge[] = [2, 0, -1, 2]Output: -1Explanation: There is no cycle in the graph. The edges are 1 -&gt; 0 -&gt; 2 &lt;- 3. Hence, 2 has no outgoing edge, so no cycle exists.
