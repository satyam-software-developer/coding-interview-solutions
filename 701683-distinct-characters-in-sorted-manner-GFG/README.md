# [Distinct Characters In Sorted Manner](https://www.geeksforgeeks.org/problems/print-different-characters-in-sorted-manner/1?page=1&category=Java&status=unsolved&sortBy=submissions)
## Easy
Given a string s, return a string containing all distinct characters from s in non-decreasing order.
Examples:
Input: s = "abdbc"
Output: "abcd"Explanation: The distinct characters in s are 'a', 'b', 'd', and 'c'. When sorted, they form "abcd".
Input: s = "fdfdfd"
Output: "df"Explanation: The distinct characters in s are 'f' and 'd'. When sorted, they form "df".
