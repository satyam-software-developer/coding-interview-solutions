# [Max Digit Sum Number in 1 to n](https://www.geeksforgeeks.org/problems/biggest-integer-having-maximum-digit-sum1704/1)
## Easy
Given a number n, find a number in the range from 1 to n such that its digit sum is maximum. If there are multiple such numbers, return the largest of them.
Examples:
Input: n = 48
Output:&nbsp;48
Explanation: There are two numbers with maximum digit sum = 12. The numbers are 48 and 39. Since 48 &gt; 39, so 48 is the answer.
Input: n = 90
Output: 89Explanation: 89 gives us the largest digit sum in the range from 1 to n. Hence the answer is 89.
