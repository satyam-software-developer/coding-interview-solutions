# [Java Streams Average](https://www.geeksforgeeks.org/problems/java-streams-average/1?page=1&category=Java&status=unsolved&sortBy=submissions)
## Easy
Given an integer array arr[], return the average of the array using streams.
Note: Average is sum of all elements divided by the number of elements.
Examples:
Input: arr[] = [1, 2, 3, 4]
Output: 2.5
Explanation: sum = 1 + 2 + 3 + 4 = 10 and average = 10/4 = 2.5
Input: arr[] = [3, 2, 1]
Output: 2.0
Explanation: sum = 3 + 2 + 1 = 6 and average = 6/3 = 2.0
Constraints:1&nbsp;≤&nbsp;arr.length&nbsp;≤&nbsp;1051&nbsp;≤&nbsp;arr[i]&nbsp;≤&nbsp;105
