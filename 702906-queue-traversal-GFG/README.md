# [Queue Traversal](https://www.geeksforgeeks.org/problems/queue-traversal-1594111322/1?page=1&category=Java&status=unsolved&sortBy=submissions)
## Easy
Given a Queue q[] containing integer elements, traverse the queue and return all its elements in an array.
Examples:
Input : q[] = [3, 4, 2, 2, 4]
Output : 3 4 2 2 4 
Input : q[] = [3, 2, 2, 7]
Output : 3 2 2 7 
Constraints:1 ≤ q.size() ≤ 1051 ≤ elements of Queue ≤ 105
