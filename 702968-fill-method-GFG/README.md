# [Fill Method](https://www.geeksforgeeks.org/problems/fill-method/1)
## Easy
Given an integer array arr[] and an integer k. Fill arr with integer k.Examples:Input: arr[] = [1, 2, 3, 4, 5], k = 67
Output: [67, 67, 67, 67, 67]
Explanation: k is 67, so we fill arr with 67.
Input: arr[] = [7], k = 99
Output: [99]
Explanation: k is 99, so we fill arr with 99.Constraints:1&nbsp;≤&nbsp;arr.length&nbsp;≤ 1030&nbsp;≤&nbsp;k, arr[i]&nbsp;≤&nbsp;106
