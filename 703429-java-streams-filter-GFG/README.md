# [Java Streams Filter](https://www.geeksforgeeks.org/problems/java-streams-filter/1?page=1&category=Java&status=unsolved&sortBy=submissions)
## Easy
Given an integer array arr[], return the maximum odd element.
Examples:
Input: arr[] = [1, 2, 3, 4]
Output: 3
Explanation: Odd elements are 1, 3. The max is 3.
Input: arr[] = [3, 2, 1]
Output: 3
Explanation: Odd elements are 3, 1. The max is 3.
Constraints:1&nbsp;≤&nbsp;arr.length&nbsp;≤&nbsp;1051&nbsp;≤&nbsp;arr[i]&nbsp;≤&nbsp;105
