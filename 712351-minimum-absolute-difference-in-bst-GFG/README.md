# [Minimum Absolute Difference In BST](https://www.geeksforgeeks.org/problems/minimum-absolute-difference-in-bst-1665139652/1)
## Medium
Given the root of a Binary Search Tree (BST) containing n (n &gt; 1) nodes, find the minimum absolute difference between the values of any two different nodes in the tree.Return the minimum absolute difference.Examples:Input: root[] = [50, 30, 70, 20, N, 60, 80]Output: 10Explanation: There are no two nodes whose absolute difference is smaller than 10.Input: root[] = [60, 30, 90, 10]Output: 20Explanation: There are no two nodes whose absolute difference is smaller than 20.
